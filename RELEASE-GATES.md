# Publication gates

This source-only candidate has not been published or installed over the canonical running app.

- MIT was selected by the owner for original app-owned source. Preserve third-party terms and review remaining provenance before distributing copied material.
- Review model/backend terms for the exact separately installed artifacts and intended use/output distribution. No weights or WanGP checkout are bundled; architectural separation does not grant model/backend permissions.
- Resolve unsupported/unpinned optional dependencies before enabling their installation. Nemotron setup is currently blocked.
- The disposable recovery fixture covers file copies, paused-queue restore and owned reimport only. Full browser, worker, service, checkpoint and provenance restoration remains unverified.
- Compare the running bridge cached intent list with preserved disk state through an existing authenticated session before declaring the production-write incident closed. Do not restore an old empty ledger or automatically replay.
- Complete clean-machine Linux onboarding, declared Node/platform matrix, a complete disposable disaster-recovery/rollback rehearsal, and authenticated real-phone verification. Fixture/mobile viewport tests alone do not establish these.
- Verify actual model reference planning, speech identity/quality and new duration behavior in deliberately authorized live runs. Model-free replies cannot prove model judgment, resource fit or generation quality.
- Fix or precisely scope remaining browser integration failures and independent audit findings. Record exact-archive validation and checksums before approval to publish.
- Establish maintainer security-report contact, support policy, contributor licensing and release ownership.
